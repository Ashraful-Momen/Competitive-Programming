# 📘 Time & Space Complexity Master Note (BN + EN)

> **Golden Rule**
>
> **Time Complexity = CPU কত কাজ করছে? (How many operations?)**
>
> **Space Complexity = Extra Memory কত লাগছে? (How much extra memory?)**

---

# Step-1 : Time Complexity আসলে কী?

ধরো তুমি ১০০ জন Student-এর নাম Print করবে।

```cpp
for(int i=0;i<n;i++)
{
    cout<<arr[i];
}
```

যদি

```
n = 5
```

Loop চলবে

```
5 Times
```

যদি

```
n = 1000
```

Loop চলবে

```
1000 Times
```

তাহলে

```
Operations ∝ n
```

অর্থাৎ

```
Time Complexity = O(n)
```

# 💡 The 30-Second Complexity Formula (যেকোনো Code-এর জন্য)

```text
                START
                  │
                  ▼
         Is there any loop?
          │              │
         No             Yes
          │              │
        O(1)      How many times?
                        │
        ┌───────────────┼────────────────┐
        │               │                │
     n times       n² (nested)      Half each time
        │               │                │
      O(n)           O(n²)          O(log n)
                        │
                        ▼
        Are loops nested or sequential?
                        │
          Nested → Multiply (n × m)
          Sequential → Add → Keep largest
                        │
                        ▼
        Any recursion?
          │
          ├─ Depth = n → Space O(n)
          └─ Depth = log n → Space O(log n)
                        │
                        ▼
        Any extra array/map/queue?
          │
          ├─ Yes → Count extra memory
          └─ No  → Space O(1)
```

## 🔑 এক লাইনে মনে রাখো

* **Time Complexity = "Code কতবার Execute হচ্ছে?"**
* **Space Complexity = "Input বাদ দিয়ে Extra Memory কত লাগছে?"**

যদি এই দুইটি প্রশ্ন প্রতিটি কোডে করতে অভ্যাস করো, তাহলে নতুন Algorithm বা অজানা Code-এরও Time ও Space Complexity নিজে থেকেই বের করতে পারবে।

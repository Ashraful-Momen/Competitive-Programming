# 🔥 Formula Reading Shortcut (Interview Trick)

| Formula                   | কী বোঝায়?                                          | Time           |
| ------------------------- | --------------------------------------------------- | -------------- |
| `T(n)=T(n-1)+O(1)`        | ১টা Recursive Call, প্রতি Call-এ Constant কাজ       | **O(n)**       |
| `T(n)=T(n-1)+O(n)`        | ১টা Recursive Call, প্রতি Call-এ n কাজ              | **O(n²)**      |
| `T(n)=T(n/2)+O(1)`        | Half Problem + Constant কাজ                         | **O(log n)**   |
| `T(n)=T(n/2)+O(n)`        | Half Problem + Linear কাজ                           | **O(n)**       |
| `T(n)=2T(n/2)+O(n)`       | দুইটা Half Problem + Merge                          | **O(n log n)** |
| `T(n)=T(n-1)+T(n-2)+O(1)` | দুইটা ভিন্ন Recursive Call                          | **O(2ⁿ)**      |
| `T(n)=2T(n-1)+O(1)`       | একই Size-এর দুইটা Recursive Call                    | **O(2ⁿ)**      |
| `T(n)=n×T(n-1)`           | প্রতিটি Level-এ n Choice (Permutation/Backtracking) | **O(n!)**      |

---

💡 **সবচেয়ে সহজে মনে রাখার Trick:**

প্রতিটি Recurrence Formula-কে এইভাবে পড়বে:

> **`T(n) = (Recursive Calls-এর Cost) + (বর্তমান Function-এর Extra Work)`**

অর্থাৎ,

* `T(n-1)` বা `T(n/2)` → **Recursive Call-এর Cost**
* `2T(...)` → **দুইটি Recursive Call**
* `nT(...)` → **প্রতিটি Level-এ nটি Choice**
* `+ O(1)`, `+ O(n)` → **বর্তমান Function-এর নিজস্ব কাজ (Recursive Call ছাড়া)**

এই নিয়মটা বুঝে গেলে আর Formula মুখস্থ করতে হবে না—যেকোনো Recursion দেখে নিজেই Recurrence Relation লিখতে পারবে।

# 🎯 The "Never Forget Again" Formula

প্রতিটি Algorithm দেখে শুধু এই ৪টি প্রশ্ন করো:

1. **একটি Function থেকে কয়টি নতুন Function Call হচ্ছে?** (1, 2, n?)
2. **Problem Size কীভাবে কমছে?** (`n-1`, `n/2`, নাকি অন্যভাবে?)
3. **প্রতি Call-এ Extra Work কত?** (`O(1)`, `O(n)`, `O(log n)`?)
4. **একসাথে Maximum কতগুলো Function Stack-এ থাকবে?** (এটাই Space Complexity)

এই ৪টি প্রশ্নের উত্তর দিতে পারলে Loop, Recursion, Divide & Conquer, Binary Search, Merge Sort, Quick Sort, Backtracking, Dynamic Programming—প্রায় সব Algorithm-এর **Time ও Space Complexity** নিজেই বের করতে পারবে।

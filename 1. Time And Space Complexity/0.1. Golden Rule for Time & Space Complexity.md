# ⭐ Rule-1 : Always Think Worst Case First

Interview-তে যদি কিছু বলা না থাকে,

**Always Assume**

```text
Time Complexity → Worst Case

Space Complexity → Worst Case
```

Example

```cpp
unordered_map<int,int> mp;
```

Average

```text
O(1)
```

Worst

```text
O(n)
```

Interview-তে দুইটাই Mention করো।

# ⭐ Rule-3 : Drop Lower Order Term

```text
O(n²+n)

↓

O(n²)
```

কারণ

Large Input এ

```text
n² >> n
```

---

# ⭐ Rule-4 : Different Variables Never Merge

অনেকে ভুল করে।

```cpp
for(i=0;i<n;i++)
{
}

for(i=0;i<m;i++)
{
}
```

Answer

```text
O(n+m)
```

NOT

```text
O(2n)
```

কারণ

```text
n != m
```

---

Nested হলে

```cpp
for(i=0;i<n;i++)
{
    for(j=0;j<m;j++)
    {
    }
}
```

Answer

```text
O(nm)
```

---

# ⭐ Rule-5 : Multiplication vs Addition

Sequential

```cpp
Loop A

Loop B
```

↓

```text
Add
```

Nested

```cpp
Loop A

↓

Loop B
```

↓

```text
Multiply
```

Shortcut

```text
Sequential = +

Nested = ×
```

# 🔥 FAANG Golden Interview Rules

এগুলো আমি তোমাকে **প্রিন্ট করে ডেস্কে লাগিয়ে রাখতে** বলব:

```text
1. Count Operations, Not Seconds.

2. Count Extra Memory, Not Input.

3. Sequential → Add.

4. Nested → Multiply.

5. Half Every Time → Log.

6. Recursive Calls → Draw Tree.

7. Ignore Constants.

8. Drop Lower Terms.

9. Worst Case First.

10. Explain Tradeoffs.

11. State Assumptions.

12. Optimize Only After Brute Force.

13. Know Your STL Complexities.

14. Think in Patterns (Sliding Window, Two Pointers, BFS/DFS, Binary Search, DP, Greedy).
```

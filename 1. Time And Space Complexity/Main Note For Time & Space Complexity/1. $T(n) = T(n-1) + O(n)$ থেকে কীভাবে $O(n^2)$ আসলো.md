$T(n) = T(n-1) + O(n)$ থেকে কীভাবে $O(n^2)$ আসলো, তা একদম সহজে Substitution Method (মান বসানোর নিয়ম) এবং রিকার্শন ট্রি (Recursion Tree) দিয়ে নিচে বুঝিয়ে দেওয়া হলো।
এখানে $O(n)$ মানে ধরে নাও প্রতিবার ফাংশনটি কল হলে ভেতরে একটি লুপ চলে যা $n$ সংখ্যক কাজ করে (যেমন: $c \cdot n$ বার কাজ, যেখানে $c$ একটি ধ্রুবক)। বোঝার সুবিধার জন্য আমরা সমীকরণটি এভাবে লিখি:
$$T(n) = T(n-1) + n$$ 
------------------------------
## ১. Substitution Method (মান বসিয়ে প্রমাণ)
আমরা মূল সমীকরণে ধাপে ধাপে $n$-এর মান কমিয়ে বসাবো:

* ধাপ ১: মূল সমীকরণ:
$$T(n) = T(n-1) + n$$ 
* ধাপ ২: এখন $T(n-1)$-এর মান বের করতে $n$-এর জায়গায় $(n-1)$ বসাই:
$$T(n-1) = T(n-2) + (n-1)$$ 
এই মানটি মূল সমীকরণে বসালে পাই:
$$T(n) = [T(n-2) + (n-1)] + n$$ 
* ধাপ ৩: একইভাবে $T(n-2)$-এর মান বসাই:
$$T(n-2) = T(n-3) + (n-2)$$ 
তাহলে সমীকরণটি দাঁড়ায়:
$$T(n) = T(n-3) + (n-2) + (n-1) + n$$ 
* ধাপ $n$ (শেষ ধাপ): এভাবে কমতে কমতে যখন বেস কেস $T(0) = 0$ বা $T(1) = 1$ এ পৌঁছাবে, তখন পুরো সিরিজটি দেখতে এমন হবে:
$$T(n) = 1 + 2 + 3 + \dots + (n-2) + (n-1) + n$$ 

## 🧮 ধারার যোগফলের সূত্র:
আমরা জানি, ১ থেকে $n$ পর্যন্ত স্বাভাবিক সংখ্যার যোগফলের সূত্র হলো:
$$\text{Sum} = \frac{n(n + 1)}{2} = \frac{n^2 + n}{2}$$ 
অ্যাসিম্পটোটিক নোটেশনে (Big O) আমরা বড় পাওয়ারটিকে রাখি এবং ছোট পাওয়ার ও ধ্রুবক (যেমন $/2$) বাদ দিয়ে দিই।
তাই, $\frac{n^2 + n}{2}$ হয়ে যায় $O(n^2)$।
------------------------------
## ২. Recursion Tree Method (ট্রি দিয়ে ভিজ্যুয়ালাইজেশন)
যদি রিকার্শন ট্রি দিয়ে চিন্তা করো, তবে প্রতি লেভেলে কী পরিমাণ কাজ হচ্ছে তা দেখা যাক:

Леভেল ০:     T(n)       ---> কাজ হয়: n
                         /
Леভেল ১:   T(n-1)       ---> কাজ হয়: n - 1
                       /
Леভেল ২: T(n-2)         ---> কাজ হয়: n - 2
                     .
                     .
Леভেল n: T(1)           ---> কাজ হয়: 1


* ১ম কলে কাজ: $n$
* ২য় কলে কাজ: $n-1$
* ৩য় কলে কাজ: $n-2$
* এভাবে মোট ট্রি-র হাইট বা গভীরতা হবে $n$ লেভেল পর্যন্ত। [1] 

সর্বমোট কাজ (Total Work):
$$\text{Total Work} = n + (n-1) + (n-2) + \dots + 2 + 1 = \frac{n(n+1)}{2} = O(n^2)$$ 
------------------------------
## 💡 একটি প্র্যাক্টিক্যাল উদাহরণ (Code Example)
এই কমপ্লেক্সিটি সাধারণত কোথায় দেখা যায়? যেমন Selection Sort বা Insertion Sort যদি রিকার্সিভলি লেখা হয়:

void selectionSortRecursive(int arr[], int n) {
    if (n <= 1) return; // বেস কেস: O(1)

    // ১টি লুপ যা n বার চলে (সবচেয়ে বড় উপাদানটি খোঁজার জন্য)
    for (int i = 0; i < n; i++) {
        // কিছু অপারেশন...
    } // এই লুপের কাজ = O(n)

    // বাকি (n-1) উপাদানের জন্য রিকার্সিভ কল
    selectionSortRecursive(arr, n - 1); // T(n-1)
}

এখানে প্রতিবার ফাংশনটি কল হওয়ার সময় একটি $n$ সাইজের লুপ চলছে, এবং পরবর্তী কলের জন্য ইনপুট সাইজ ১ কমে যাচ্ছে। ফলে এটি হুবহু $T(n) = T(n-1) + O(n)$ সমীকরণ মেনে চলে এবং এর মোট সময় লাগে $O(n^2)$।

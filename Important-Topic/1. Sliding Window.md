# Step 1: প্রথমে Problem বুঝি

ধরো তোমাকে বলা হলো—

> একটি Array দেওয়া আছে। **পরপর ৩টি Element-এর মধ্যে Maximum Sum বের করো।**

Example

```text
Array:

[2, 4, 1, 8, 5, 3]

Window Size = 3
```

```text
[2 4 1] = 7

[4 1 8] = 13

[1 8 5] = 14

[8 5 3] = 16
```

```text
16
```

↓

# C++ Code

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> arr = {2,4,1,8,5,3};

    int k = 3;

    int currentSum = 0;

    // First Window
    for(int i=0;i<k;i++)
        currentSum += arr[i];

    int maximum = currentSum;

    // Sliding
    for(int i=k;i<arr.size();i++)
    {
        currentSum =
            currentSum
            - arr[i-k]
            + arr[i];

        if(currentSum > maximum)
            maximum = currentSum;
    }

    cout << maximum;
}
```

Output

```text
16
```

# কখন Sliding Window ব্যবহার করবে? (Interview Shortcut)

যদি Problem-এ নিচের যেকোনো শব্দ দেখো, তাহলে Sliding Window-এর কথা আগে ভাববে:

* **Contiguous Array**
* **Subarray**
* **Substring**
* **Consecutive Elements**
* **Window Size = K**
* **Longest/Shortest Subarray**
* **Maximum/Minimum Sum of K elements**
* **At most K**, **Exactly K**, **No more than K** (Variable Window-এর ইঙ্গিত)

এগুলো দেখলেই Nested Loop করার আগে নিজেকে প্রশ্ন করো:

> **"আমি কি আগের Window-এর তথ্য ব্যবহার করে নতুন Window-এর উত্তর বের করতে পারি?"**

যদি উত্তর **হ্যাঁ** হয়, তাহলে Sliding Window ব্যবহার করার সম্ভাবনা খুব বেশি।
